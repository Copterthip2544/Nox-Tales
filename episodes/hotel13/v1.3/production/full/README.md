# โรงแรมห้อง 13 — แขกที่ห้ามเช็กเอาต์

ช่อง: Frame Tales | บท: v1.3

**พักการตัดต่อและเรนเดอร์เพิ่ม เพื่อให้ผู้ใช้ตรวจภาพก่อน**

เริ่มที่ [หน้ารวมตรวจภาพ](review/README.md) มีภาพเวอร์ชันปัจจุบัน 43 ภาพ แบ่งชุดละ 5 ภาพ ภาพฉากเปิดเดิมอยู่ใน [masters](../masters) และภาพที่เลิกใช้อยู่ใน [archive](archive/README.md)

ภาพที่ผู้ช่วยตรวจเบื้องต้นแล้วยังไม่ถือว่าได้รับอนุมัติจากผู้ใช้ ภาพที่มีการแก้ไขต้องตรวจเวอร์ชันใหม่อีกครั้ง

เสียงพากย์เดิมพร้อมครบ 111 ช่วง ไม่ต้องสร้างเสียงซ้ำ แผนทั้งเรื่องประมาณ 12 นาที 57 วินาที รวมช่วงการแสดงและเสียงประกอบ ยังไม่มีไฟล์คลิปเต็มพร้อมส่งออก

ภาพตอนหลังตำรวจมาถึงจนถึงโทรศัพท์หนึ่งปีต่อมา (J01–J08) ยังไม่สร้างในชุดตรวจนี้

ไฟล์ใน `tools` เป็นงานเตรียมการผลิตที่สำรองไว้ ไม่ได้เรียกใช้ workflow ตัดต่ออัตโนมัติ การเรนเดอร์ถูกกั้นไว้ระหว่างสถานะรอตรวจภาพ
