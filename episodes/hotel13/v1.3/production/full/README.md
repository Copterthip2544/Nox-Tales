# โรงแรมห้อง 13 — แขกที่ห้ามเช็กเอาต์

ช่อง Frame Tales | บท v1.3

ผู้ใช้อนุญาตให้เลือกภาพที่ใช้ได้อัปโหลดและเริ่มตัดต่อแล้ว

ภาพใหม่ปัจจุบัน 51 ภาพ และภาพฉากเปิด/สถานที่เดิม 13 ภาพ รวม 64 ภาพ ดู [แกลเลอรี](review/README.md) แบ่งชุดละ 5 ภาพ ภาพเก่าไม่ใช้ใน archive

เสียงพากย์อนุมัติครบ 111 ช่วง ไม่สร้างซ้ำ ความยาวแผน 12:57.24 นาที ใช้แพนแนวนอนหรือซูมเบา ไม่มีภาพสั่น

อยู่ระหว่างเรนเดอร์คลิปเต็ม ไฟล์เต็มยังไม่พร้อมจนกว่าจะมีรายงานการเรนเดอร์และตรวจไฟล์จริง
