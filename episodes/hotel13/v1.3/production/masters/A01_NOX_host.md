# NOX — ภาพเปิดเรื่อง

![NOX storyteller](A01_NOX_host.png)

ภาพจริงสำหรับช่วงเปิดและปิด ใช้ NOX avatar ที่อ้างอิง character sheet เดิมและห้องเล่าเรื่องของ Frame Tales เป็น reference ไม่มีตัวหนังสือในภาพ ป้ายกุญแจเว้นว่างสำหรับใส่เลข 13 ภายหลัง

นาฬิกาพกปิดอยู่ใต้มือแมว โทรศัพท์ในห้อง NOX เป็นอุปกรณ์ห้องเล่าเรื่อง ไม่ใช่เครื่องเดียวกับเคาน์เตอร์โรงแรม

ขนาดต้นทาง 1672×941 ใช้ต้นทางนี้สำหรับแพน/ซูมเล็กน้อยและตรวจระยะครอปก่อนส่งออก 1920×1080 ยังไม่ใช่วิดีโอที่เรนเดอร์แล้ว
