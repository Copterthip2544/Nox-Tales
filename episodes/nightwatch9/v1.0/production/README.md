# Frame Tales — กฎ 9 ข้อสำหรับเจ้าหน้าที่เฝ้ากล้องกะดึก

ชุดภาพและระบบตัดต่อฉบับผลิต v01 สำหรับวิดีโอภาษาไทย 1920×1080 / 30fps แบบ Narrated Motion Slideshow

- ใช้เสียงพากย์ที่ผู้ใช้ฟังตรวจผ่านแล้ว 145 ช่วง / 149 หน่วยสร้างเสียงเดิม ไม่มีการเรียก TTS ใหม่
- เสียง Nox คือ Charon; Nox รูปลักษณ์/ชุด/สีจาก Character Sheet และท่านั่งสัดส่วนแมวจากตอนแรก ใช้ภาพ v05 ที่ผู้ใช้อนุมัติสำหรับตอนนี้
- ภาพทุบประตูใช้เวอร์ชันล่าสุดตามจุดมาร์กของผู้ใช้: นาฬิกาอยู่ข้อมือยก มือที่ยกเป็นมือซ้าย ภาพก่อนแก้ไม่นำเข้ารายการผลิต
- ใช้แพนแนวนอนหรือซูมนุ่มนวล ไม่มี screen shake
- จอจริง 6 จอ แสดงกล้อง 9 ช่อง โดยกล้อง 6 อยู่จอเดี่ยวล่างกลาง ห้องน้ำเล็กอยู่ภายในห้องควบคุม
- กฎ 7 ที่หายไม่เลื่อนเลขกฎ 8/9; กล้อง 6 นำเวลาปัจจุบัน 10 นาที; ช่วงปิดจอนับครบ 150 เฟรม = 5 วินาที
- ดนตรีและ SFX เป็นเสียงที่สังเคราะห์ในระบบตัดต่อ แยกแทร็กจากเสียงพูด ปรับระดับได้

ภาพต้นฉบับอยู่ใน `scene_assets/` และภาพอ้างอิงตัวละครอยู่ใน `../references/characters/` เปิด `review_gallery.html` หลังดาวน์โหลดโฟลเดอร์เพื่อดูภาพทั้งหมด

## ทำซ้ำการเรนเดอร์

Workflow `Render Nightwatch9 full film v01` กู้ไฟล์เสียงจากงานที่อนุมัติ สร้างไทม์ไลน์จากความยาวเสียงจริง ประกอบตัวเลข/ข้อความอย่างแม่นยำ แล้วเรนเดอร์และตรวจไฟล์ โดยไม่ใช้ Gemini/ElevenLabs API เพิ่ม

ผลลัพธ์อยู่ใน GitHub Actions artifact `nightwatch9-full-film-v01`: MP4, ซับไทยแยก SRT, รายงานตรวจไฟล์ และ shot list การเรนเดอร์ไม่ได้เผยแพร่ลง YouTube/Facebook

ก่อนเผยแพร่ให้ตรวจภาพและเสียงของคลิปเต็มอีกครั้ง การตรวจสรีระเป็นการตรวจด้วยสายตาและการแก้ตามจุดที่ผู้ใช้ระบุ ไม่ใช่การรับประกันว่าภาพ AI ทุกพิกเซลถูกต้อง
