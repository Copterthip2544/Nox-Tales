# ทดลองเสียง Nox Tales

บัญชีนี้ส่งคืน `models/gemini-3.8-flash-tts` ในผล Models API วันที่ 11 พฤศจิกายน 2026
เลือกโมเดลนี้ตามคำขอเดิมของผู้ใช้ และใช้ schema รุ่น 3.8 จากเอกสาร Google

## วิธีรัน
1. เปิด Actions → **Preview Thai character voices** → **Run workflow**
2. เลือก `main` และ character เป็น `all` เพื่อทำ 3 ไฟล์ หรือเลือกตัวเดียว
3. ติ๊ก `confirm_generation` เมื่อพร้อมให้เรียก API สร้างตัวอย่างเสียงจริง
4. กด Run workflow รอผลแล้วดาวน์โหลด artifact `nox-voice-previews`
5. ฟัง `nox.wav`, `manager.wav`, `lin.wav` และดู manifest ซึ่งระบุเวลาวัดจากไฟล์จริง

เพิ่ม workflow นี้อย่างเดียวไม่สร้างเสียง รันด้วยมือเท่านั้น ไม่มี trigger จาก push
สูงสุด 3 คำขอต่อ run ไม่มี retry อัตโนมัติ ไม่สร้างบทเต็มหรือโคลนเสียงบุคคลจริง
เมื่อมีข้อผิดพลาดให้ดูไฟล์ที่สำเร็จแล้ว และเลือกเฉพาะตัวละครที่ยังไม่มีไฟล์ แทนรัน all ซ้ำ

## ตัวเลือกเสียงตั้งต้น (ยังไม่ใช่เสียงที่อนุมัติแล้ว)

| ตัวละคร | เสียง | เป้าหมาย |
|---|---|---|
| Nox | Charon | ผู้เล่าสุขุม ชัด อบอุ่น |
| ผู้จัดการ | Gacrux | ลักษณะเสียง Mature; ทดลองกำกับให้เป็นชายสูงวัย |
| ลิน | Leda | ลักษณะเสียง Youthful; ทดลองความเหมาะกับเด็กหญิง |

คำอธิบาย prebuilt ไม่ใช่การรับรองอายุหรือเพศที่ฟังได้จริง ต้องฟังทดสอบ หากเสียงไม่ตรงให้เลือกจาก Extended Voice Library หรือออกแบบเสียงในขั้นถัดไป
ข้อความอ่านจริงแยกจาก `speech_metadata.style` และไม่มีชื่อผู้พูดปนใน text จึงไม่ตั้งใจให้ระบบอ่านป้ายชื่อ
รุ่น 3.8 แบบ unary คืน WAV โดยปริยาย จึงเขียนไฟล์โดยตรงและตรวจ RIFF/WAVE ไม่ห่อหัว WAV ซ้ำเหมือนตัวอย่างโค้ดของรุ่นเก่า

## เช็กลิสต์ฟัง
- อ่านไทยและวรรณยุกต์ถูก ไม่มีสำเนียงหลุดจนเสียความหมาย
- อ่านครบตามข้อความ ไม่มีอ่านคำสั่งการแสดงหรือชื่อผู้พูด
- Nox ฟังต่อเนื่องสบาย ผู้จัดการต่างจาก Nox และลินไม่แหลมจัด
- ไม่มีเสียงตัด แตกพร่า หรือช่องว่างผิดปกติ
- การผ่าน API ยังไม่ถือว่าผ่านคุณภาพเสียง
